# Rula: запуск на русском

Rula — открытый проект [Игоря Якушева](https://igor-ya.ru/): русскоязычный голосовой AI-аватар с локальным распознаванием речи, Qwen, синтезом речи и анимацией лица. Браузер показывает 3D-модель VRM; вычисления выполняются на рабочей станции с NVIDIA GPU.

Статус — **development preview**. Публичное интерактивное демо сейчас отключено. Этот сайт содержит документацию и доступен независимо от GPU-сервера.

## Начало работы

```sh
git clone https://github.com/ykshv/rula.git
cd rula
```

Для запуска нужны Windows с WSL2, NVIDIA GPU, Docker с поддержкой GPU и загруженные модели. Последовательность установки, команды запуска и локальные адреса приведены в [инструкции](quickstart.md). Скачивание моделей требует доступа к сети; основной путь обработки голоса рассчитан на локальное выполнение.

Перед использованием проверьте [критерии приёмки](verification.md): готовность моделей и GPU, задержку ответа, прерывания, синхронизацию звука и лица, длительную работу и работу без внешней сети. Целевые метрики не являются результатами измерений конкретного стенда.

Об устройстве системы — [архитектура](architecture.md) и [статья про on-prem голосовых агентов](https://igor-ya.ru/posts/on-prem-voice-agents/).
